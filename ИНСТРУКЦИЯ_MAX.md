# Инструкция: привязка мини-приложения к боту MAX и обновление расписания

Бот уже создан и прошёл модерацию. Нужно только заменить ссылку в его
настройках на нашу. Всё делается в браузере, ничего устанавливать не надо.

---

## Часть 1. Привязываем наше мини-приложение к боту (один раз)

1. Зайди на платформу **MAX для партнёров** — **business.max.ru**
   (вход по номеру телефона, на который регистрировали бота).

2. Открой раздел **«Чат-боты»**.

3. **Нажми на нужного бота** в списке — откроется его панель управления.

4. Перейди в **«Расширенные настройки»** и нажми **«Настроить»**.

5. В поле для ссылки **сотри старую ссылку** и вставь нашу:
   ```
   https://colderuopen-art.github.io/raspisanie/
   ```
   Проверь, что ссылка:
   - начинается с `https://`
   - без пробелов в начале и в конце
   - скопирована целиком, со слэшем на конце

6. Выбери вид кнопки — **«Открыть»**
   (это текст кнопки, которую увидят люди в чате с ботом).

7. Нажми **«Сохранить»**.

Готово. У всех, кто откроет бота, кнопка теперь ведёт на наше расписание.
Переустанавливать MAX или заново искать бота никому не нужно — у людей
всё поменяется само.

---

## Часть 2. Как обновить расписание занятий (когда пришлют новый файл)

1. Открой репозиторий на GitHub:
   **github.com/colderuopen-art/raspisanie**

2. Нажми **Add file → Upload files** (кнопка справа вверху, над списком файлов).

3. Перетащи мышкой новый файл расписания в окно загрузки.

   **Главное правило:** файл должен называться точно так же —
   ```
   Расписание.xlsx
   ```
   Если новый файл называется иначе (например, «Расписание (2).xlsx») —
   сначала переименуй его на компьютере, потом загружай.
   GitHub сам заменит старый файл новым.

4. Листай вниз и нажми зелёную кнопку **«Commit changes»**,
   в появившемся окне — ещё раз **«Commit changes»**.

5. Подожди 1–2 минуты — у всех пользователей откроется уже новое расписание.
   Ничего больше делать не надо.

Проверка: открой сайт, под заголовком «Расписание занятий» должна стоять
новая дата в строке «Обновление …».

---

## Часть 3. Как обновить расписание звонков (картинку)

Всё то же самое, только файл другой:

1. **github.com/colderuopen-art/raspisanie** → **Add file → Upload files**
2. Перетащи новую картинку. Она должна называться точно так же:
   ```
   Звонки.jpg
   ```
   (именно `.jpg` — если прислали картинку в другом формате, сначала
   пересохрани её как jpg)
3. **Commit changes** → через 1–2 минуты картинка обновится у всех.

## Если что-то пошло не так

| Что видишь | Причина | Что делать |
|---|---|---|
| На сайте «Ошибка: не найден файл» | Файл назван не так | Проверь имя: `Расписание.xlsx`, буква в букву |
| Сайт показывает старое расписание | Деплой ещё идёт | Подожди 2–3 минуты, обнови страницу |
| Кнопка бота открывает старый сайт | Ссылку не сохранили | Повтори Часть 1, проверь, что нажал «Сохранить» |
| Таблица обрезана / нет колонок | В Excel сдвинули строку заголовков | Строка 2 должна быть: `Группа | 1 пара | 2 пара | …` |
