# Версия для GitHub Pages

Эта папка — полностью статический сайт: чтение Excel происходит прямо в браузере
пользователя (библиотека SheetJS, файл `xlsx.full.min.js` лежит рядом, интернет для неё не нужен).

## Файлы
- `index.html` — само приложение
- `xlsx.full.min.js` — библиотека чтения Excel (не трогать)
- `logo.png` — логотип техникума в шапке (не трогать)
- `Расписание.xlsx` — файл расписания (можно заменять)
- `Звонки.jpg` — картинка «Расписание звонков» (тоже можно заменять)

## Как выложить на GitHub Pages (бесплатно)
1. Создай на GitHub новый репозиторий (например, `raspisanie`), тип — **Public**.
2. Загрузи туда все пять файлов из этой папки (кнопка **Add file → Upload files**).
3. Зайди в **Settings → Pages**.
4. В разделе **Build and deployment**: Source = **Deploy from a branch**,
   Branch = **main**, папка = **/(root)**. Сохрани.
5. Через 1–2 минуты сайт будет доступен по адресу вида:
   `https://<твой-логин>.github.io/raspisanie/`

## Как обновить расписание (главное)
1. Открой репозиторий → **Add file → Upload files**.
2. Перетащи новый файл с **тем же именем**:
   - `Расписание.xlsx` — чтобы обновить расписание занятий
   - `Звонки.jpg` — чтобы обновить картинку звонков
   GitHub сам заменит старый файл новым.
3. **Commit changes** → через минуту у всех пользователей новые данные.
   Страницу обновлять специально не нужно — при каждом открытии грузятся свежие файлы.

Доступ к репозиторию можно выдать через **Settings → Collaborators → Add people** —
тогда человек сможет заменять файл прямо с браузера, ничего устанавливать не надо.

## Требования к файлу расписания (как и раньше)
- Листы: ПОНЕДЕЛЬНИК … СУББОТА (лист «итог» игнорируется)
- Строка 1: название дня + дата (она показывается пользователям)
- Строка 2: `Группа | 1 пара | 2 пара | …` — количество пар любое
- Строка 3 и ниже: группы и предметы
- Имя файла должно быть именно `Расписание.xlsx`, картинки — `Звонки.jpg`
